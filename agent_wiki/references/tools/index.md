# Tools

The wiki's own machinery, kept inside the bundle so that copying `agent_wiki/`
into another project brings everything needed to validate it.

`okf.py` is the entry point, and `tests/` proves it works. Attribution for the
derived code is in `NOTICE`.

# Concepts

* [okf.py](okf-tool.md) - Validates this bundle against OKF v0.2.
