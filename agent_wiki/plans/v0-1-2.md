# Known risk

The `.ico` uses the on-dark favicon (light ink). The user's Windows uses the dark theme; on a light
taskbar or light Explorer view, the 16–48 px frame would be faint. The release has no variant for
unknown backgrounds; if this matters, it goes back to the identity workshop, not into the app.
