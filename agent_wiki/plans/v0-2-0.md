# Ground rules

The rules of [v0.1.0](/plans/v0-1-0.md) still hold: every task cites its spec ids; a spec that
turns out wrong is changed first, then the code; the core knows no room. The review question
becomes concrete: *does this file name `learn` or `choose`?* Only `app/src/rooms/<id>/`, the room
list (RS-4) and tests may.

**Two releases** (q-r5-release): Part A ships alone and must leave Learn exactly as it is; Part B
lands on top of it. Version numbers: Part A is **v0.2.0** (the format change makes it a minor
version); Part B ships as the next version once accepted (v0.2.x or v0.3.0, the user's call at
release time).

Checks run for every slice: `npm run check` 0/0, the TypeScript unit tests, the Rust tests, and the
Playwright suite on a private port. Prompt changes also need the three-run eval gate (PQ-33).
