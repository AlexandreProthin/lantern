# Improvements

- **I1** Remove the Home and Gallery icons at the top right of the graph view; they duplicate the global top bar.
  Keep only the tree-layout icon ([graph-view](/specs/graph-view.md)).
- **I2** Graph view bottom-right control order: Zoom out, Recenter, Zoom in.
- **I3** Gallery cards all have the same size.
- **I4** Gallery: a title too long for one line is trimmed (ellipsis) while the card is not selected.

# Feature requests

- **F1** Right-click a node in the graph view for the same actions as the end of the node panel:
  lit node: More options, Add my own node, Delete; understood node: More options, Add my own node;
  dark node: Light it up, Dismiss, Delete. Reuse the panel's action rows ([learn-room](/specs/learn-room.md)).
- **F2** An "Open" button above the legend, the same size as the "Legend" button. Click opens the folder that
  contains the active `subject.json` in Explorer; right-click copies the path to that file to the clipboard,
  with visible user feedback.
- **F3** Hovering a link in the text (one that points to another node) plays a subtle light travelling along the
  connection from the node being read to the target, to preview where a click lands.
- **F4** Code blocks are highlighted according to their language (highlight.js is already a dependency, so first
  check why fences are not highlighted).
- **F5** Welcome: an optional way to give extra context about the graph direction or initial hook. **Designed
  2026-10-04** in `agent_design/welcome-context/` (final r004-01 *Ride, settle*, recipe
  `agent_design/welcome-context/RECIPE.md`) and **specified** the same day on the user's instruction: Shift+Enter in
  the subject opens an optional **direction** (at most 500 characters) inside the capsule; *Carry the lantern in*
  shows only while the field has focus; the direction is stored on the subject, sent with every later generation as
  `DIRECTION_BLOCK`, and editable in the subject menu; suggestion chips still fill only the title. Specs:
  [welcome-gallery](/specs/welcome-gallery.md) WG-1/3/8 to 11, [domain-model](/specs/domain-model.md) DM-41,
  [rooms-spaces](/specs/rooms-spaces.md) RS-15/16/19, [learn-room](/specs/learn-room.md) LR-19/44,
  [context-assembly](/specs/context-assembly.md) CA-2/37/40/52, [tutor-protocol](/specs/tutor-protocol.md) TP-13/20
  (prompts become `learn-2`: rerun the eval gate before keeping them), [product-scope](/specs/product-scope.md)
  PS-21/29. Remaining: implementation. B6 (cursor and gradient) touches the same capsule edge, so do them together.
