Interaction hypothesis

The quietest change to v0.1.0: the subject line keeps its 38 px underline and the direction is the same object one size down (16 px), centred, so the page still reads top to bottom: subject, direction, button. Opening it is a light travelling from the subject down to the new line (the Welcome ember language). It stays open while it holds text.

Keys (same in all three)

Enter carries the lantern in from either part. Shift+Enter in the subject opens (or jumps to) the direction; in the direction it is a new line. Backspace in an empty direction, or Esc, closes it and returns to the subject. Arrow Up at the start of the direction goes back to the subject.
