What the tutor loses

1. Whole mapLoses nothing about the map's shape, but pays for it on every call. Past the budget the outline must be cut or the call fails; the first thing dropped is usually the oldest dialogue or the outline's tail, with no rule about which. Remembers nothing about how the learner did on other nodes beyond their state tags.
2. NeighbourhoodCannot see distant open nodes' hooks, so it may re-propose a node that already exists elsewhere in the map. Sees other lit nodes by title only, so it cannot link to what was actually said there. Turns older than the last 8 are reduced to one summary.
3. Neighbourhood + memoryGains short stored summaries of lit nodes and a learner profile, but those summaries must be written and kept current (extra calls, possible staleness). Still blind to distant open nodes; summaries beyond the 1500-token cap drop the least recently visited nodes. A wrong profile can bias the tutor.
