# Identity workshop

Read AGENTS.md then RESUME.md. The initial project is projects/lantern/.
No design has begun. This is a plain-file workflow: no server, gallery or automatic
agent runner is required. Ask an agent to read this folder and resume the chosen project.

- AGENTS.md: complete reusable workflow and persistence rules.
- RESUME.md: startup, recovery and portable handoff.
- REUSE.md: starting another project without inherited preferences.
- MECHANISMS.md: inspected source mechanisms and deliberate adaptations.
- templates/: project, request, round, candidate, evidence and checkpoint forms.
- projects/lantern/: established brief, draft contract, rubric, request, log,
  checkpoint, artifact inventory and reserved asset directories.

All project paths are relative. Plain files are the operating interface. No prior chat
is needed. The next task is phase 0 design-contract work when the user initiates it.
