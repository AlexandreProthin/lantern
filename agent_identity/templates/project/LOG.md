# Persistent event and decision log
Append only; corrections cite superseded IDs.
Event: E####, timestamp/timezone, actor, request/state revisions, attempt/phase/step,
action, artifact paths and next action.
Decision: also D####, verbatim input/source, owner, rationale, alternatives, selected/
rejected/deferred IDs, evidence, reusable fragments, reopening conditions and invalidated
descendants. Separate agent recommendation from user decision.
