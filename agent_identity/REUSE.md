# Reuse

Copy the harness or create projects/<new-slug>/ from templates/project/. Create rounds/,
checkpoints/, refs/, assets/source/, assets/exports/ and final/. Retain generic AGENTS.md,
RESUME.md and templates. Replace placeholders only with established facts and provenance.
Initialize request/state revision 1, contract/rubric version 0, no attempts or candidates,
and a setup log event. Set permission boundary from the actual user request.
Do not copy Lantern choices, requirements, rejections or assets to the new project.
New project creation does not authorize premature visual proposals. Version future
harness changes and record the version used by each attempt; retain historical workflows.
