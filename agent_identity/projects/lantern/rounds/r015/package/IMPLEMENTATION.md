# Implementation recipe
Open runtime/review.html directly, offline, no server required. Load body.js, motion.js, styles.js in that order. styles.js preserves rawSvg and wraps LanternMotion.svg; loading it twice is unsupported. review.js demonstrates controls and reduced-motion handling, not a production integration API.
Use unique SVG IDs for each actor. LanternMotion.svg(index, pose, uniqueId) renders styled actor; pose(index,time) generates accepted gestures, still(index) gives reduced/static destination. Returned markup is generated solely from internal sources. Do not inject untrusted strings into SVG IDs.
Explicit play owns a finite scene clock. Preserve current x/y/feet on interruption (see review.js), stabilize 180ms, freeze or apply static reduced fallback. Cancel on hidden/background and do not replay on show. Define continuity from arbitrary states before binding real room events. Keep permanent idle disabled until agreed.
Use exports/favicon with contrast-appropriate ink; the final duplicated size suffix records source variant and PNG size. SVG masters and PNGs are transparent. Mark exports omit the face deliberately; companion exports include it. CSS tinting applies to monochrome SVG sources only; warm colored assets retain tokens.
Reproduce exports with sources/export.cjs from the enclosing round (requires Node and sharp at configured path); exports already included so no tool/runtime is needed to consume them. Rendering tool path is local configuration, not a product dependency. Record any future renderer changes and rerun alpha/dimension/native checks.
