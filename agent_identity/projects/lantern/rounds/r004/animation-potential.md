# Potentiel d'animation — non implémenté
Source utilisateur feedback.md ; décisions D0008.
- Posé : pieds qui apparaissent pour se déplacer. Rétractabilité au repos est une hypothèse
  agent compatible avec le souhait, pas un détail d'animation approuvé.
- Suspendu : peut se balancer, tomber ou rester immobile. Attache dédiée proposée dans
  les formes pour conserver l'affordance ; fixation et chute à définir plus tard.
- Chauffe et déplacement libre : sens en attente ; question utilisateur déjà posée.
  Possibilité de flottement/vol n'est pas une réponse présumée.
Ces intentions servent à éviter une forme sans potentiel de mouvement. Ni déclencheurs,
durées, simulation ni animation rendue dans la présente phase 1. Les états statique,
masqué et mouvement réduit restent des contraintes du contrat.
