# Evaluation rubric
Version: 0; status: generic framework; priorities/thresholds pending agreement
Criteria: contract fit, distinctive silhouette, actual-size legibility, continuity across
favicon/app/companion, character range, motion meaning/readability, visual consistency,
background/monochrome behavior, reduced-motion/static fallbacks, production feasibility.
For applicable criteria record conditions, evidence, pass/fail/untested and confidence.
Optional scores: 0 fails, 1 weak, 2 adequate, 3 strong; N/A needs a reason.
Agree hard gates/weights in phase 0. Hard failures cannot be averaged away.
Scores support discussion and never constitute human selection.
