# Rendering conditions
Pillow 10.4.0; CPU geometric cubic sampling (40 segments per curve), 8x supersampling, Lanczos downsample, RGB sRGB assumed. White/#181818 polarity; negative eyes use background. SVG sources contain white eye knockouts for light preview only; use plain variants or backdrop-color eye holes for dark integration. No browser renderer equivalence claimed.
Favicon board: native pixels at left, 3x nearest-neighbor at right . App exports 64/128/256. Each size exported with/without eyes. No screen-DPI or user perception validation.
